# PCIe链路训练 - 快速参考

## 什么是链路训练？

PCIe设备在建立通信前**自动协商和配置**的过程，确保两个设备能够可靠通信。

## 核心流程

```
上电/复位
    │
    ▼
┌─────────┐
│ Detect  │ ──> 检测链路是否存在 (~24ms)
└────┬────┘
     │
┌────▼────┐
│ Polling │ ──> 发送TS1，CDR锁定 (~12ms)
└────┬────┘
     │
┌────▼──────────┐
│ Configuration │ ──> 协商参数，对齐通道 (~16ms)
└────┬──────────┘
     │
┌────▼────┐
│   L0    │ ──> 正常工作，传输数据
└─────────┘
```

**总时间：约50-100ms**

## 各阶段作用

| 阶段 | 目的 | 关键操作 |
|------|------|---------|
| **Detect** | 检测链路 | 发送检测信号，确认设备存在 |
| **Polling** | CDR锁定 | 发送TS1训练序列，恢复时钟 |
| **Configuration** | 参数协商 | 协商速度/宽度，对齐通道 |
| **L0** | 正常工作 | 传输数据包（TLP, DLLP） |

## 训练序列（TS1/TS2）

### TS1（第一类训练序列）
- **用途**：初始训练，CDR锁定
- **发送时机**：Polling和Configuration阶段
- **内容**：链路参数（速度、宽度等）

### TS2（第二类训练序列）
- **用途**：参数确认
- **发送时机**：Configuration阶段
- **内容**：确认协商的参数

### 训练序列的作用
```
1. 提供跳变 ──> CDR可以锁定频率
2. 参数协商 ──> 速度和宽度
3. 通道对齐 ──> 多通道时对齐
4. 符号锁定 ──> 8b/10b符号边界
```

## 参数协商

### 链路宽度
```
设备A: 支持 x1, x2, x4, x8, x16
设备B: 支持 x1, x2, x4
结果:  x4 (双方都支持的最大值)
```

### 链路速度
```
设备A: 支持 Gen1, Gen2, Gen3, Gen4
设备B: 支持 Gen1, Gen2, Gen3
结果:  Gen3 (双方都支持的最高速度)
```

### 降级机制
如果协商失败，自动降级：
```
尝试: x16 Gen4 ──> 失败
尝试: x8  Gen4 ──> 失败
尝试: x4  Gen3 ──> 成功 ✓
最终: x4 Gen3链路
```

## 多通道对齐

对于x2/x4/x8/x16链路：

```
通道0: ──[TS1]──>
通道1: ──[TS1]──>
通道2: ──[TS1]──>
通道3: ──[TS1]──>

对齐过程:
1. 每个通道独立CDR锁定
2. 检测所有通道的TS1
3. 对齐符号边界
4. 确保时钟同步
```

## 与CDR的关系

```
Polling阶段:
TS1 ──> 提供跳变 ──> CDR锁定频率

Configuration阶段:
TS1/TS2 ──> CDR持续跟踪 ──> 优化采样点

结果:
所有通道CDR锁定，采样点优化，准备传输数据
```

## 实际示例

### 示例：x4 Gen3链路训练

```
0-24ms:   Detect阶段
          ✓ 检测到设备

24-36ms:  Polling阶段
          设备A ──[TS1]──> 设备B
          设备B ──[TS1]──> 设备A
          ✓ CDR锁定

36-52ms:  Configuration阶段
          设备A ──[TS1: x4, Gen3]──> 设备B
          设备B ──[TS1: x4, Gen3]──> 设备A
          ✓ 参数协商完成
          
          设备A ──[TS2]──> 设备B
          设备B ──[TS2]──> 设备A
          ✓ 参数确认

52ms+:    L0状态
          ✓ 链路训练完成
          ✓ 可以传输数据
```

## 常见问题

### Q: 链路训练需要多长时间？
**A:** 正常情况下50-100ms
- Detect: ~24ms
- Polling: ~12ms  
- Configuration: ~16ms

### Q: 训练失败会怎样？
**A:** 设备会尝试降级（降低速度或宽度），如果完全失败，链路不会建立。

### Q: 可以手动控制吗？
**A:** 通常不可以，链路训练是硬件自动完成的。

### Q: 如何查看链路状态？
**A:** 
```bash
lspci -vvv | grep -A 5 "LnkSta"
# 输出: LnkSta: Speed 8GT/s, Width x4
```

## 关键要点

✅ **自动执行**：硬件自动完成，无需软件干预  
✅ **双向协商**：两个设备互相协商参数  
✅ **容错性**：支持降级以建立链路  
✅ **与CDR配合**：训练序列帮助CDR锁定  
✅ **多通道支持**：自动对齐所有通道
