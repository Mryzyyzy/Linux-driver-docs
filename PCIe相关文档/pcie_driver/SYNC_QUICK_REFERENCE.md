# 系统同步 vs 源同步 - 快速参考

## 核心区别（一句话总结）

- **系统同步**：发送端和接收端共享一个系统时钟
- **源同步**：数据和时钟一起从发送端传输

## 可视化对比

### 系统同步架构

```
        ┌─────────────┐
        │  系统时钟   │
        │  (CLK_SYS)  │
        └──────┬──────┘
               │
        ┌──────┴──────┐
        │             │
    ┌───▼───┐     ┌───▼───┐
    │发送端 │     │接收端 │
    │       │     │       │
    │ DATA──┼────>│       │
    └───────┘     └───────┘
    
问题：时钟和数据路径长度不同 → 时序偏差
```

### 源同步架构

```
    ┌───────┐         ┌───────┐
    │发送端 │         │接收端 │
    │       │         │       │
    │ CLK───┼────────>│ CLK   │
    │ DATA──┼────────>│ DATA  │
    └───────┘         └───┬───┘
          │                │
          └── 一起传输 ────┘
          
优势：时钟和数据路径匹配 → 时序偏差小
```

## 关键参数对比

| 参数 | 系统同步 | 源同步 |
|------|---------|--------|
| **时钟来源** | 系统时钟 | 发送端时钟 |
| **时钟路径** | 独立分配 | 与数据一起 |
| **路径匹配** | ❌ 不需要 | ✅ **必须匹配** |
| **时钟偏斜** | 较大 (ns级) | 很小 (ps级) |
| **最大频率** | ~100MHz | **>500MHz** |
| **时序裕量** | 小 | **大** |
| **PCB复杂度** | 中等 | 高（需匹配） |

## 时序窗口对比

### 系统同步时序窗口

```
时钟周期: ████████████████ (10ns @ 100MHz)
          │
有效窗口: ████ (4.5ns) ← 受时钟偏斜影响
          │
          └─ 时钟偏斜消耗了大量时间
```

### 源同步时序窗口

```
时钟周期: ████████ (5ns @ 200MHz)
          │
有效窗口: ███████ (3.8ns) ← 时钟偏斜很小
          │
          └─ 时钟和数据匹配，偏斜很小
```

## 应用场景快速选择

### 选择系统同步 ✅

- 低速接口 (< 100MHz)
- 多设备共享时钟
- 成本敏感应用
- 简单控制接口

**典型应用：**
- 传统微控制器总线
- SDR SDRAM
- GPIO扩展

### 选择源同步 ✅

- 高速接口 (> 100MHz)
- 点对点传输
- 性能优先
- 现代接口标准

**典型应用：**
- DDR SDRAM (DQS)
- PCIe
- MIPI接口
- 高速ADC/DAC

## 设计要点

### 系统同步设计

```
✓ 时钟树综合
✓ 时钟偏斜最小化
✓ 时钟和数据路径长度差异控制
```

### 源同步设计

```
✓ 时钟和数据走线长度匹配 (±0.1mm)
✓ 并行走线
✓ 相同PCB层和过孔数量
✓ 严格控制阻抗
```

## 性能公式

### 系统同步最大频率

```
f_max ≈ 1 / (t_co + t_prop + t_setup + t_skew_global)
      ≈ 1 / (2ns + 3ns + 1ns + 2ns)
      ≈ 125 MHz
```

### 源同步最大频率

```
f_max ≈ 1 / (t_skew_cd + t_setup)
      ≈ 1 / (0.5ns + 0.5ns)
      ≈ 1000 MHz (1 GHz)
```

## PCIe的特殊情况

PCIe使用**改进的源同步**：

```
✓ 嵌入时钟（8b/10b编码）
✓ 时钟数据恢复（CDR）
✓ 链路训练优化采样点
✓ 串行传输（多通道）
```

## 记忆技巧

**系统同步 = 共享时钟**
- 像会议室里所有人看同一个时钟
- 但每个人距离时钟的距离不同（偏斜）

**源同步 = 时钟随数据**
- 像快递包裹附带时间戳
- 数据和时钟一起到达（匹配）

## 常见问题

**Q: 为什么源同步频率更高？**
A: 时钟偏斜小，时序裕量大，可以支持更短的时钟周期。

**Q: 源同步需要更多信号线吗？**
A: 不需要，只是时钟的传输方式不同。

**Q: 可以混合使用吗？**
A: 可以，系统时钟用于控制，源同步用于高速数据。

**Q: PCIe是哪种方式？**
A: 改进的源同步（嵌入时钟 + CDR）。
