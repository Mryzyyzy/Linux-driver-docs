## 数据流示例

### 示例 1: CPU 读取 DDR 内存

```
CPU Core0 (load 指令)
    │
    ▼
L2 Cache (miss)
    │
    ▼
AXI Master (发起读请求)
    │
    ▼
NI - CPU 侧
    │  AXI → NoC Packet
    │  - 源地址: CPU NI
    │  - 目标地址: DDR Controller NI
    │  - 数据: 读请求 (地址、长度)
    ▼
NoC Router 0
    │  路由决策: 往 DDR Controller 方向
    ▼
NoC Router 5
    │  继续路由
    ▼
NI - DDR Ctrl 侧
    │  NoC Packet → AXI
    │  - 还原为 AXI 读事务
    ▼
DDR Controller
    │  解析地址，生成 DDR 命令
    ▼
DDR PHY
    │  访问 DDR 内存条
    ▼
DDR 内存条
    │  返回数据
    ▼
(反向路径返回数据到 CPU)
```

### 示例 2: PCIe 设备 DMA 到系统内存

```
PCIe 设备 (外部板卡)
    │  发起 Memory Write TLP
    ▼
PCIe PHY/SerDes
    │  串行数据 → 并行
    ▼
PCIe Controller
    │  TLP → AXI Master 事务
    │  - 目标: 系统内存地址
    ▼
NI - PCIe Ctrl 侧
    │  AXI → NoC Packet
    │  - 源: PCIe Controller
    │  - 目标: DDR Controller
    │  - QoS: 高优先级 (DMA)
    ▼
NoC Router 2
    │  路由到 DDR Controller
    ▼
NoC Router 5
    │  继续路由
    ▼
NI - DDR Ctrl 侧
    │  NoC Packet → AXI
    ▼
DDR Controller
    │  写数据到 DDR
    ▼
DDR 内存条
    │  数据写入完成
```

### 示例 3: 多核 CPU 并发访问

```
CPU Core0 ──┐
            ├──> NoC Router 0 ──> 路由到不同目标
CPU Core1 ──┤
            │
CPU Core2 ──┤
            │
CPU Core3 ──┘

同时访问:
- Core0 → DDR (读)
- Core1 → PCIe (配置)
- Core2 → NPU (启动任务)
- Core3 → DDR (写)

NoC 支持:
- 多路径并行
- QoS 优先级调度
- 带宽保证
```

## NoC 关键特性

### 1. 拓扑结构

```
Mesh (网格) 拓扑:
    R0 ── R1 ── R2 ── R3
    │     │     │     │
    R4 ── R5 ── R6 ── R7
    │     │     │     │
    R8 ── R9 ── R10 ─ R11

- 每个 Router 连接 4 个方向 (东西南北)
- 支持多路径路由 (负载均衡)
- 可扩展到任意规模
```

### 2. Virtual Channel (VC)

```
物理链路:
    ┌─────────────────┐
    │  Physical Link  │
    └─────────────────┘

逻辑上分为多个 VC:
    VC0: 高优先级 (实时数据)
    VC1: 中优先级 (普通数据)
    VC2: 低优先级 (后台任务)

避免死锁，支持 QoS
```

### 3. QoS 机制

```
优先级调度:
- 实时数据 (音视频) → 最高优先级
- DMA 传输 → 高优先级
- CPU 普通访问 → 中优先级
- 后台任务 → 低优先级

带宽保证:
- 为关键路径预留带宽
- 防止低优先级流量阻塞高优先级
```

## 与传统总线的对比

### 传统共享总线

```
CPU ──┐
      │
DMA ──┼──> 共享总线 (带宽受限)
      │
GPU ──┘
      │
  所有设备竞争同一根总线
```

### NoC 架构

```
CPU ──> Router ──> 多路径并行
DMA ──> Router ──> 高带宽
GPU ──> Router ──> QoS 保证

每个路径独立，带宽叠加
```

## 总结

### NoC 架构的优势

1. **高可扩展性**: 可以轻松添加新的 IP 模块
2. **高带宽**: 多路径并行，带宽叠加
3. **低延迟**: 分布式路由，路径优化
4. **QoS 支持**: 优先级调度，带宽保证
5. **时钟域解耦**: 支持不同时钟域

### 关键组件

- **Network Interface (NI)**: AXI ↔ NoC 协议转换
- **Router**: 路由决策，包转发
- **Link**: 物理链路，支持多 VC
- **QoS 机制**: 优先级、带宽管理

### 典型应用场景

- 多核 CPU 系统
- 高性能 SoC (AI、GPU、NPU)
- 复杂外设系统 (多个 PCIe、以太网等)
- 需要 QoS 保证的实时系统
